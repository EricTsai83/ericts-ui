active = false

開啟後，在描邊完成前關閉；接著快速開關，觀察上面兩種方式。

目前啟用減少動態效果，示範改以淡入淡出呈現。

draw · 反向收回

建議方式：切換時接續當前進度。

適合 focus、hover、toggle。

draw · 向前退出

舊版方式：切換時從固定端點重播。

中途關閉時，可能先補滿再退出。

trace · 播放一次

畫入 → 向前退出

適合一次性提示。播完即消失，active 仍可為 true。

loop · 重複描繪

反覆畫入、退出

適合持續處理中的狀態。關閉即停止。

orbit · 線段繞行

固定短線段沿輪廓前進

適合等待指示。維持短線段，不畫滿整圈。
